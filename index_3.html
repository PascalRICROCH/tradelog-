Sauvegarde sur GitHub
La page a besoin d'un jeton GitHub pour écrire tradelog.json dans ton dépôt. Il reste uniquement dans ce navigateur. Tes données ne sont jamais perdues si le jeton expire : elles restent ici, il suffit de coller un nouveau jeton.
  1. ➜ Créer un nouveau jeton (formulaire déjà rempli) — connecte-toi à GitHub si demandé.
  2. Vérifie Repository access → Only select repositories → tradelog- et Contents → Read and write, puis Generate token.
  3. Copie le jeton (github_pat_…), colle-le ci-dessous, puis Tester.
🤖 MAJ Claude du journal Excel
Récupère Journal_Trading_KTA_2026_COMPLET_Avril-Novembre.xlsx sur GitHub, ajoute les trades XAU/USD importés avec « Importer Ufunded » qui n'y sont pas encore (analyse + graphique de chaque trade), te le télécharge, puis le publie sur GitHub — comme « Menu → Publier une MAJ du journal Excel ».

Ordre conseillé : ① Importer Ufunded (ton nouveau relevé) → ② MAJ Claude.
Importer un relevé Ufunded
Dépose le PDF « Single-Currency account statement » téléchargé depuis Ufunded. Les P&L sont additionnés jour par jour et ton calendrier est rempli automatiquement. Tes notes sont conservées. Tu peux aussi déposer une sauvegarde .json du journal.
