Sauvegarde sur GitHub
GitHub Pages ne fait qu'afficher la page : il ne peut pas enregistrer tout seul. Pour écrire le fichier tradelog.json dans ton dépôt, la page a besoin d'un jeton GitHub (une seule fois par navigateur ; il reste sur cet ordinateur uniquement).

Crée-le ici : github.com → Fine-grained token · Repository access : Only select repositories → tradelog- · Permissions : Contents → Read and write.
